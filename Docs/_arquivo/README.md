## Regras desta pasta

1. **Só entra, não sai.** Nada aqui é apagado: é registro histórico.
2. **Não é referência técnica.** Se um número ou regra daqui divergir do v3, **vale o v3**.
3. **Cuidado com IP.** `MegaManX_WorldBible.md` **cita obra de terceiros** — é material de estudo interno. Nada daqui
   entra no jogo, em apresentação pública ou em build (`IP-001` e `IP-005` no backlog).
